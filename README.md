# MellorCraft 1.3.1 Server
A way to play MellorCraft 1.3.1 together! Works Cross-Platform using a Python server.

# Prerequisites
1. Windows, Mac, or Linux PC
2. Latest Python version installed

# How to start your world
1. Clone this repository by clicking code and then Download ZIP
2. Extract the ZIP file
3. Open the extracted folder and open your terminal in that folder
4. Type python mellorcraft_server.py in there
5. Your server is now running!

# How to join your world
1. Find the IPv4 address of your PC by opening a second terminal and typing ipconfig
2. Type http://YOUR_IP:8000 into another devices' browser
3. Welcome!
